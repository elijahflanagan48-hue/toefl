# NOEON TOEFL — прототип оболочки (этап P1)

PWA для подготовки к TOEFL iBT (формат 2026). Vanilla JS (ES-модули) + Vite, без фреймворка.
Пока без сервера: данные — заглушки в `src/data/mock.js` (их форма = контракт для API на этапе P2).

## Запуск
```
npm install
npm run dev      # локально
npm run build    # сборка в dist/ (относительные пути — подходит для GitHub Pages)
```

## Структура
```
index.html                 оболочка: левая панель (≥960px) + плавающее меню (телефон)
src/main.js                hash-роутер, навигация по ролям, делегирование событий, горячие клавиши
src/styles/tokens.css      токены: светлая/тёмная тема, цвета секций R/L/W/S, шрифты Madefor
src/styles/base.css        каркас, шапка экрана, меню «пилюля», левая панель
src/styles/components.css  кнопки, карточки, сегменты, ладдер 1–6, неделя, таблицы, модалки
src/styles/screens.css     раскладки экранов (телефон → планшет → компьютер)
src/styles/exam.css        экзаменационная оболочка (всегда светлая, нейтральная)
src/lib/ctw.js             генератор Complete the Words по правилу ETS (floor(n/2) букв, каждое 2-е слово)
src/lib/util.js            шкала 1–6 → CEFR, общий балл с округлением ETS (.25/.75 вверх)
src/views/*.js             экраны: today, train, mock, progress, profile, teacher, exam-reading
```

## Маршруты
Ученик: `#/today` `#/train/R|L|W|S` `#/mock` `#/progress` `#/profile`
Учитель: `#/t/home` `#/t/students` `#/t/review` `#/t/review/:id` `#/t/content`
Экзамен: `#/exam/reading` (демо-модуль: 10 CtW + 2 Daily Life + 5 Academic Passage, 12 мин)

## Горячие клавиши
Экзамен: ←/→ Back/Next · 1–4 вариант ответа · R Review · Esc закрыть окно.
Проверка работ: 0–5 балл · Ctrl+Enter сохранить · J/K следующая/предыдущая.

## Правила (из гайда проекта)
- Тулбар экзамена по-английски; Help не останавливает таймер; таймер можно скрыть, в последнюю минуту он показывается принудительно.
- Back и Review — только внутри модуля Reading; после перехода к модулю 2 вернуться нельзя.
- Порог маршрута MST (60%) — настраиваемый: ETS его не публикует.
- localStorage — только для настроек устройства (тема, роль в прототипе), каждое обращение в try/catch.
